## ① 課題名

じゃんけん BOSS バトルゲーム

## ② 課題内容（どんな作品か）

- じゃんけんを使って BOSS と戦う HP 制バトルゲームです。
- プレイヤーが選んだ手と CPU の手で勝敗を決定します。
- 勝つと敵 HP にダメージ、負けると自分がダメージを受けます。
- 3 連勝するとクリティカルダメージ（追加ダメージ）が発生します。
- HP が 0 になると勝敗結果画面が表示され、再挑戦できます。

## ⑤ 工夫した点・こだわった点

- HP バーのアニメーションにより「バトル感」を演出。
- 3 連勝でクリティカルが発生するゲーム性を追加。
- CPU の手に「学習風ロジック」を追加して難易度を微調整。
- 勝敗ログを最新順で表示し、視認性と臨場感を向上。
- ダークテーマをベースにデザインし、ゲーム UI に寄せた世界観を構築。
- ボタンやメッセージのアニメーションでユーザー体験を強化。

## ⑥ 難しかった点・次回トライしたいこと（又は機能）

- CPU の挙動をランダム以上にするロジック設計が難しかった。
- HP 管理と勝敗、連勝カウントなど複数状態の同時管理に苦戦した。
- DOM 操作が多く、表示更新のタイミング整合に注意が必要だった。
